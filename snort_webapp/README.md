# Enhancing Snort-Based Intrusion Detection with Machine Learning IP Verification

B.Tech Project-I (BCSE497J) — VIT

A hybrid Intrusion Detection System (IDS) that combines Snort's rule-based detection with
machine learning (Random Forest and XGBoost) to verify alerts, reduce false positives, and
classify network traffic as **benign** or **malicious**, trained on the CICIDS 2017 Balanced Dataset.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Add the full dataset. This repo ships with `data/sample_dataset.csv`, a tiny 21-row
   excerpt (DDoS rows only) that documents the expected column format — it is **not**
   enough to train a real model since it contains just one class. Download the full
   **CICIDS 2017 Balanced Dataset** and place it at:
   ```
   data/CICIDS_balanced.csv
   ```
   (This filename is already covered by `.gitignore`, so it won't be committed.)

3. Train the models:
   ```bash
   python training/ll.py
   ```
   By default this looks for `data/CICIDS_balanced.csv`. To use a different path or
   filename, either pass it as an argument:
   ```bash
   python training/ll.py path/to/your_dataset.csv
   ```
   or set the `DATA_PATH` environment variable. This generates `rf_model.joblib`,
   `xgb_model.joblib`, `scaler.joblib`, `label_encoder.joblib`, and `columns.pkl`
   inside `model/`.

   Optionally, run the evaluation script the same way to get classification reports
   and a saved confusion-matrix plot (`model/confusion_matrices.png`):
   ```bash
   python training/evaluate_and_plot.py
   ```

4. Run the web app:
   ```bash
   python app.py
   ```
   Then open `http://127.0.0.1:5000/` and upload a Snort-generated CSV log to classify it.

## Results

| Model         | Accuracy (%) | Precision (%) | Recall (%) | F1-Score (%) |
|---------------|-------------|----------------|------------|---------------|
| Random Forest | 94.33       | 93.80          | 94.10      | 94.00         |
| XGBoost       | 95.45       | 95.00          | 95.30      | 95.25         |

Integrating the ML verification layer reduced the false positive rate from ~18% (standalone
Snort) to ~5% (Snort-ML hybrid).

## Note on included model files

This repo ships with **demo model files** in `model/` (`rf_model.joblib`, `xgb_model.joblib`,
`scaler.joblib`, `label_encoder.joblib`, `columns.pkl`) so the Flask app runs out of the box.
They were trained only on `data/sample_dataset.csv`, which contains just 21 rows and a single
class (`DDoS`) — so these models will **always predict "DDoS"** and are useful only for
verifying the upload → predict → results pipeline works, not for real detection.

Also, `xgb_model.joblib` here is **not actually an XGBoost model** — it's a second
`RandomForestClassifier` saved under that filename as a stand-in, since XGBoost wasn't
available when these demo files were generated.

To get real, meaningful models:
1. Add the full CICIDS 2017 Balanced Dataset at `data/CICIDS_balanced.csv`.
2. Make sure `xgboost` is installed (`pip install xgboost`, already in `requirements.txt`).
3. Re-run `python training/ll.py` — this overwrites the demo files in `model/` with a real,
   properly trained Random Forest and XGBoost model pair.
